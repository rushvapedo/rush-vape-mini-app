# Rush Vape — Telegram Mini App

Это стартовый frontend-прототип магазина.

## Что уже есть
- адаптивный тёмный интерфейс;
- логотип Rush Vape;
- возрастное подтверждение;
- категории;
- поиск;
- карточки товаров;
- корзина;
- локальное сохранение корзины;
- базовая интеграция Telegram WebApp.

## Следующие этапы
1. Разместить frontend на HTTPS.
2. Подключить Mini App к @RushVape66_bot через BotFather.
3. Перенести товары в базу данных.
4. Сделать сервер/API.
5. Сделать админ-панель.
6. Сделать реальные заказы и уведомления админу.

Токен Telegram-бота не хранится в этом проекте.
